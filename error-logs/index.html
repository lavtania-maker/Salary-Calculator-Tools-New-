Error Type Reference

input

User entered invalid data

Example: empty salary, letters in number field

Fix: Validate input before calculating

calculation

Salary computation failed or returned wrong result

Example: NaN result, division error

Fix: Check formula logic in calculateSalary()

system

JavaScript crash — unexpected runtime error

Example: undefined variable, null reference

Fix: Check stack trace in Details column

promise

Async operation failed (API call, fetch, etc.)

Example: Google Sheets API not responding

Fix: Check network tab in DevTools

api

External API returned an error

Example: Sheets URL wrong, Firebase error

Fix: Verify API URL and credentials

How to Use This Page

  • 1
    Go to https://salarycalculator.my and use the calculator normally or trigger errors by entering bad data
  • 2
    Come back to https://salarycalculator.my/error-logs — errors are automatically loaded from browser storage
  • 3
    Use the filter buttons to show only a specific type of error
  • 4
    Click "Show Stack" on any row to see the exact line of code that caused the error
  • 5
    Click "Copy" to copy the stack trace and share it for debugging
  • 6
    Click "Export CSV" to download all logs as a spreadsheet
  • 7
    Click "Clear All Logs" to wipe the log history after reviewing
