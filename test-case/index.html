Severity Fix Guide
HIGH — Immediate Fix
System-breaking issues. Must be hotfixed before next deployment. Core calculation logic must NOT be touched without validation.
MEDIUM — Schedule Fix
Functional issues that affect usability but do not break the system. Fix within the next sprint or release cycle.
LOW — Batch Fix
Cosmetic or minor issues. Can be batched and fixed together in a periodic UI polish update.
